rdv on the web

Megakernels built with rdv (a differentiable, megakernel-based GPU engine on Vulkan), exported to WebGPU: the node graph's GLSL is compiled to SPIR-V, its buffer-reference pointers are lowered to offsets into a single storage buffer, Tint translates it to WGSL, and everything (shader, node memory, data) ships as one self-contained JavaScript module.

Volume transmittance

Ray-marched transmittance through the Disney cloud (154×85×125 voxels, trilinear sampling). Orbit, pan and zoom with the mouse; per-frame draw times shown live.

Volume radiance

Unbiased path tracing of the same cloud (delta tracking with a voxel majorant, ratio-tracked shadow rays, Henyey-Greenstein phase) lit by a single directional light, refined progressively. Light, density, anisotropy and bounce controls; per-sample timings shown live.

Volume deep features

The VolumeDeepProfile feature inspector: 13 per-pixel features of the medium (transmittance-threshold depths, reduced/effective transmittance, sun NEE, importance-sampled environment NEE, scattering albedo, interaction probability) - any three mapped to RGB, with the profile's ablation flags and medium/light controls.

HaloRT · neural volume rendering

The full HaloRT pipeline in the browser: rdv computes the deep features of the cloud on the GPU, and the HaloRT network (two UNets, exported to ONNX, run by ONNX Runtime Web on the same WebGPU device) turns them into sun and sky radiance - no data leaves the GPU. Light, medium and camera controls; per-stage timings.
