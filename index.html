rdv on the web

Megakernels built with rdv (a differentiable, megakernel-based GPU engine on Vulkan), exported to WebGPU: the node graph's GLSL is compiled to SPIR-V, its buffer-reference pointers are lowered to offsets into a single storage buffer, Tint translates it to WGSL, and everything (shader, node memory, data) ships as one self-contained JavaScript module.

Volume transmittance

Ray-marched transmittance through the Disney cloud (154×85×125 voxels, trilinear sampling). Orbit, pan and zoom with the mouse; per-frame draw times shown live.
